# Maintenance Database (MySQL) — Schema + Minimal Demo Seed

This container uses MySQL. Connection info is stored in `db_connection.txt`:

- `mysql -u appuser -pdbuser123 -h localhost -P 5000 myapp`

## How the schema + seed were applied (one statement at a time)

Per project rules, DDL/DML is executed via CLI using **one statement per `-e` invocation**.

Below are the exact commands (copy/paste friendly). Each line is a single statement.

> Note: MySQL will print a warning about using a password on the command line; this is expected in this environment.

### Connectivity check

```bash
mysql -u appuser -pdbuser123 -h localhost -P 5000 -e "SELECT 1;" myapp
```

### Schema (tables + constraints + indexes)

